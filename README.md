# Agricultural development reshapes global hotspots of compound water–nitrogen pressure

This repository contains plotting code and processed inputs for reproducing
the figures associated with the manuscript.

The bundled inputs support regeneration of 13 figures without external downloads.
Extended Data Fig. 7 requires additional benchmark data. Main Fig. 1 is
author-created artwork.

See the [figure reproduction guide](./global-compound-water-nitrogen-pressure-reproduction/README.md) for software
requirements, run commands, external data sources, and the mapping between
figures and source files.
